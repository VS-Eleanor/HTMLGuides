Guidelines · 08

Do's & Don'ts

Core rules derived from the VX system patterns. Follow these to keep the UI consistent, accessible, and maintainable across all HRMS modules.

check_circle Do
  • Use module-specific icon colours consistently across the sidebar, dashboard, and tables.
  • Use the correct semantic button colour — green for approval, red for rejection, indigo for neutral primary actions.
  • Apply status badges with both a dot indicator and a label — never colour-only.
  • Use #32325D for primary text and #8898AA for secondary or label text.
  • Apply live search to replace pagination in lookup/selector components.
  • Keep table header rows at #E3E7F4 and row separators at #CAD1D7.
cancel Don't
  • Don't open full-screen modals for inline field lookups — use combobox dropdowns instead.
  • Don't display ALL CAPS company or employee names — apply Title Case at render time.
  • Don't introduce hex colours outside the defined palette; always use a token.
  • Don't mix button sizes within the same form action row — pick one size and stick to it.
  • Don't use pagination when search is available — 31 pages defeats the purpose of a lookup.
  • Don't render icon-only action buttons without an aria-label or tooltip for accessibility.

Pattern · 09

Workflow States & Actions

Every submission in VX moves through a defined set of states. Each state controls which actions are available. Never show an action button for an action that is not permitted in the current state.

State Hex Available Actions Description
Draft #FB6340 Edit · Save as Draft · Submit · Delete Saved but not yet submitted. Employee can continue editing or delete entirely.
Pending #5E72E4 Withdraw Submitted and awaiting approver action. Only withdrawal is permitted by the submitter.
Pending Resubmit #FB6340 Resubmit · Save as Draft · Withdraw Returned by approver for correction. Employee edits and resubmits.
Approved #2DCE89 — No actions Final state. Changes have been applied to the HRMS record.
Rejected #F5365C — No actions Final state. No changes applied. Employee must start a new submission.
Withdrawn #F5365C — No actions Final state. Retracted by employee before approver acted.

Actions by Role

Show only the actions a role is permitted to perform. Never display approver actions to an employee, or employee actions to an approver. Button visibility is role-driven.
